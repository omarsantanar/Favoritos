# Servicio de investigación/modelos (futuro)

**No implementado ni conectado en v0.1.** Este directorio reserva un servicio Python reproducible que leerá datos con marca temporal, versión de modelo y procedencia. Producirá probabilidades únicamente tras su validación y evaluación temporal fuera de muestra. Nunca debe generar «probabilidades» usando únicamente ejemplos inventados, ni publicar un pronóstico sin cuota verificable y contraargumentos.

Entrada futura: evento oficial, participantes confirmados/probables, observaciones con timestamp, mercado y línea. Salida futura: probabilidad, incertidumbre, método, datos disponibles y faltantes, hora de corte y decisión editorial (`publicable` / `sin_seleccion`).
