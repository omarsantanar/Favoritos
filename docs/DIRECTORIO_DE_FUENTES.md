# Directorio de consulta editorial — Favoritos

**Fecha de comprobación:** 27 de octubre de 2026. **Disciplinas activas:** NBA, NFL, MLB, NHL, MMA y boxeo.

Este es un documento de investigación y no una sección del portal público. Los sitios indicados son oficiales o los respectivos proveedores de precios; ello **no** implica permiso para extraer, descargar masivamente o redistribuir su información.

**Estado de integración:** ninguna de estas casas está conectada como feed gratuito de cuotas. Se consultan manualmente cuando sea legalmente accesible y sus condiciones lo permitan. En el portal no habrá botones para realizar apuestas ni cuentas de jugadores.

La única API candidata de cotizaciones sigue siendo **The Odds API — Starter gratuito**, y debe respetarse su cupo y términos. No confundir esta API con las webs de las casas.

## Regla de trazabilidad

Para cada línea observada conservar casa, evento, deporte, mercado, selección, cuota decimal, hora UTC y fuente. Especificar claramente el tiempo transcurrido; una cuota antigua no es una cuota vigente. La popularidad se declara solo con datos verificables de porcentaje de boletos o dinero, no se infiere de cambios de precio.

**Publicación:** análisis de 300 caracteres máximo incluida la sugerencia; sin garantías ni ejecución de apuestas.
